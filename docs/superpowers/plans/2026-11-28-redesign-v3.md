# Redesign v3, "Systems in motion": Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` checkboxes.

**Goal:** Restyle the live site (golu-portfolio-one.vercel.app) into a calm, cinematic, premium portfolio that works for both clients and recruiters. It must be full-screen, uncluttered, have one "aah" moment per scroll, and be as immersive on mobile as on desktop. Build on the existing code; do not start from scratch.

**User direction (2026-11-28):**
- **Theme:** "Balanced: Systems in motion".
- **Approach:** reuse the existing engine.
- **Flow clips:** keep them as full-screen scroll scenes.
  - The Flow watermark stays **visible**: never crop, blur, cover or scale it out of view.
  - Each clip is labelled "AI-generated footage".
- **Remove the clutter:** the sticky-note collage, the stacked missed-call cards, the "Less chaos. More clients." pitch and the Untangled counter.

**Architecture:**
- **Keep:** Vite, GSAP 3.13 (ScrollTrigger and SplitText, both free), Lenis, and `film.js`, which keeps its proximity loading, decode window and eased frame lerp. Also keep `agent-demo.js`, the bar, the menu and the Playwright harness.
- **Restyle:** tokens, sections and copy.
- **Visual work in code:** new visuals use canvas 2D, CSS, or three.js where a scene needs real 3D (lazy-loaded, with fallbacks; see `docs/REDESIGN.md` §4).

## Global constraints

**Palette** (dark-first):

| Role | Value |
|---|---|
| Stage | `#0B1426` |
| Surface | `#12203A` |
| Line | `#1E2E4D` |
| Text | `#EEF1F7` |
| Muted | `#9DA9C2` |
| Accent (Mint) | `#3DDC97` (the only saturated colour) |
| Light-section paper | `#F3F1EC` (use sparingly, e.g. the contact section) |

- **Text contrast:** at least 4.5:1, measured.

**Type:** Inter (display weights 500 and 600, tracking −2% on large sizes) and JetBrains Mono for labels.
- φ type scale: mobile 12/16/26/42/68, desktop 12/18/29/47/76/123/199.
- φ space scale: mobile 6/10/16/26/42/68, desktop 7/11/18/29/47/76.

**Layout:**
- One idea per viewport.
- Generous negative space.
- At most 2 type sizes plus 1 label size visible per screen.
- No overlapping card collages.

**Motion:**
- Every scroll-linked animation is ScrollTrigger scrub (0.6–1) driven by Lenis.
- Animate only transform and opacity.
- Ease `cubic-bezier(0.16,1,0.3,1)`.
- Text reveals use SplitText (lines or words, masked).
- Reduced motion shows the end states statically.
- The existing no-jump tests extend to every new animation.

**Films:**
- Full-bleed `100vw × 100svh` while pinned, cover-fit, anchored so the bottom-right watermark stays in view.
- Navy overlay gradient for text legibility; it must not touch the watermark corner.
- Section ranges: hero 300vh, the others 200vh.

**Loader:**
- The G·K mark draws in, and a 0–100 counter tracks the **real** preload of the first hero frames, the fonts, and DOMContentLoaded.
- A curtain reveals the page.
- At most 2.5 s on a fast connection; capped at 6 s even if loading is unfinished.
- Skipped when reduced motion is on (show a static mark for 300 ms maximum).

**Skeletons:** every media slot (work images, the About photo, film posters) shows a shimmer skeleton until loaded. The shimmer is disabled when reduced motion is on.

**Mobile:**
- No horizontal scroll from 320 to 1920.
- Tap targets ≥44 px.
- The header and the WhatsApp bar stay pinned and clear of content.
- Use the 9:16 film sets.

**Honesty** (unchanged):
- StepQ: "Client project · Website + iOS + Android".
- TeachGenie and Brivia: "Founding team · [role TBC]".
- No invented metrics, and every sample is labelled.

**Recruiter needs:**
- LinkedIn, GitHub and CV links, each with a TBC chip until provided.
- A skills / tech-stack list.
- Availability status.
